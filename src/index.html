    จำนวนนี้รวม tools ที่ต้องเปิดเพิ่ม

    นับชื่อ built-in tools ที่ไม่ซ้ำภายในแต่ละ server รวมตัวเลือกเสริม ไม่รวม custom plugins, tools ที่เว็บลงทะเบียนเพิ่ม หรือ SDK/CLI APIs ที่ไม่ได้เปิดเป็น MCP tools
